# 멍멍냥냥 🐶

박자에 맞춰 뚱뚱한 강아지 천사를 밀어 맞추는 리듬 퍼즐.

👉 **플레이: https://bamhobak.github.io/mungnyang/**

## 조작
한 마디(4박)가 한 턴입니다.

| 1박 | 2박 | 3박 | 4박 |
|---|---|---|---|
| 읽기 | 읽기 | **누르기** — 옮길 강아지 고르기 | **드래그** — 밀 방향 |

- 같은 색 3개 이상을 가로·세로로 모으면 터집니다. 2×2 뭉치도 터집니다.
- 4개 한 줄 → 직교하는 줄 통째로, 5개 → 판 위 그 색 전부, ㄱ·ㄴ·+ → 별 폭발
- 4마디마다 레벨이 오르고 템포가 빨라집니다.
- 떨어질 강아지를 3박에 **누른 채로 버티면** 안 떨어지고, 놓는 순간 떨어집니다.

## 폰에서
브라우저로 열고 **홈 화면에 추가**하면 전체화면 세로 앱처럼 뜹니다.
소리는 첫 **시작** 버튼을 눌러야 나옵니다. 헤드폰을 쓰면 판정이 정확해집니다.
